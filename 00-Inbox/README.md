# Inbox

Área temporária para informações que ainda não foram classificadas.

## Conexões principais

- Índice institucional: [[10-Simplifique/README|Simplifique Knowledge Vault]].
- Skill de estruturação: [[06-Skills/Estado-de-Clareza-v0.2|Estado de Clareza v0.2]].
- Primeira validação do agente: [[00-Inbox/Agente/primeiro-registro-hermes|Primeiro teste do Hermes]].
- Destinos de classificação: [[01-Clientes/Clientes|Clientes]], [[02-Projetos/Projetos|Projetos]], [[03-Reunioes/Reunioes|Reuniões]], [[04-Decisoes/Decisoes|Decisões]], [[05-SOPs/SOPs|SOPs]], [[06-Skills/Skills|Skills]] e [[08-Aprendizados/Aprendizados|Aprendizados]].

## Pode entrar aqui

- Anotações rápidas
- Informações recebidas de clientes
- Resumos ainda não processados
- Ideias
- Links
- Demandas ainda sem contexto suficiente
- Conteúdo capturado automaticamente

## Regra

A Inbox não é armazenamento permanente.

Toda informação deve posteriormente ser:

- descartada;
- transformada em demanda;
- associada a um cliente ou projeto;
- registrada como decisão;
- convertida em SOP;
- convertida em skill;
- registrada como aprendizado.

## Fluxo para Estado de Clareza

```text
Captura na Inbox
→ classificação por cliente, projeto ou operação
→ aplicação da Skill Estado de Clareza
→ registro no Histórico de Clareza
→ atualização de projetos, decisões e métricas
```
