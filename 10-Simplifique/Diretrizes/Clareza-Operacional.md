# Princípio de Clareza Operacional

> Ninguém me enrola porque tudo é explícito, rastreável e verificável.

## Todo projeto deve ter

- Mapa de entregas
- Responsável por cada entrega
- Prazo
- Status
- Próximo passo
- Dependências
- Critério de pronto
- Registro de acordos
- Histórico de mudanças
- Lista de bloqueios
- Indicadores principais
- Próxima decisão necessária

## Perguntas padrão de gestão

- Quem é o responsável?
- Qual é o prazo?
- O que exatamente falta?
- O que está impedindo?
- Desde quando?
- O que já foi feito para resolver?
- Qual é o próximo passo?
- Quando posso cobrar novamente?
- Isso já estava combinado?
- O que precisa sair para isso virar prioridade?

## Regra para agentes

Ao analisar um projeto, não apresentar apenas narrativa.

Sempre que possível, identificar:

1. responsável;
2. prazo;
3. status;
4. bloqueio;
5. dependência;
6. próximo passo;
7. decisão pendente;
8. evidência utilizada.

Quando alguma dessas informações não existir, declarar explicitamente que a informação está ausente.

Não inventar responsáveis, prazos, decisões ou status.
